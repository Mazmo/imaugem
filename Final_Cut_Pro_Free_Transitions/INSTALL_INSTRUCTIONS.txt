Guia completo para instalar Motion Templates no Final Cut Pro
================================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 1: TIPOS DE FICHEIROS E O QUE SIGNIFICAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

.localized    → Pasta "localizada" do macOS — é uma pasta, não um ficheiro.
               Contém os dados do template. O nome aparece traduzido no Finder.

.moti         → Ficheiro de template Apple Motion (transição individual).
               Instalação: copia para a pasta de templates do FCP.

.motr         → Variante de template Motion (rig interativo).
               Instalação: igual ao .moti.

.moef         → Motion Effect — usado por plugins como FxFactory.
               Não se instala manualmente (gerido pela app FxFactory).

.fcptemplate  → Bundle de template FCP (pode conter .moti/.motr dentro).
               Clica duas vezes para instalar automaticamente.

.mov          → Ficheiro de vídeo overlay (ex: CinePacks).
               NÃO é um plugin — arrasta para a timeline do FCP.
               Muda o blend mode para "Screen" ou "Add".

.pkg          → Instalador macOS — executa e segue as instruções.
               ATENÇÃO: Verifica a origem antes de instalar.

.dmg          → Imagem de disco macOS (ex: BretFX Power Tools).
               Abre o .dmg, abre o .pkg dentro e instala.

.zip          → Arquivo comprimido — descompacta primeiro (clica duas vezes).
               Dentro estará uma pasta .localized ou .fcptemplate.

PARTE 2: CAMINHO DE INSTALAÇÃO DOS MOTION TEMPLATES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CAMINHO PRINCIPAL para transições:
~/Movies/Motion Templates.localized/Transitions.localized/

Caminho alternativo (versões antigas do FCP):
~/Movies/Motion Templates/Transitions/

NOTA: O "~" significa a tua pasta Home (ex: /Users/teu_nome/)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 3: CRIAR A PASTA SE NÃO EXISTIR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

No Terminal do MAC, copia e cola estes comandos:

  mkdir -p ~/Movies/"Motion Templates.localized"/"Transitions.localized"

Para verificar se já existe:
  ls ~/Movies/ | grep -i motion

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 4: DOWNLOAD DO MIXKIT NO MAC (SEM LOGIN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O Mixkit oferece ~18 transições gratuitas sem qualquer login ou email.
Licença: Mixkit Free License (uso comercial, sem atribuição necessária)

OPÇÃO A — Download pelo browser (mais fácil):
1. Abre no browser: https://mixkit.co/free-final-cut-pro-templates/transitions/
2. Clica em cada template
3. Clica no botão "Free Download"
4. O ficheiro .zip é baixado imediatamente

OPÇÃO B — Download em bloco via Terminal no Mac:
  cd ~/Downloads/Final_Cut_Pro_Free_Transitions/downloads/

  # Templates confirmados:
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-sliding-square-transition-664.zip"
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-fading-frame-transition-666.zip"
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-zoom-backwards-transition-667.zip"
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-color-distortion-glitch-668.zip"
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-color-splash-transition-669.zip"
  curl -L -O "https://assets.mixkit.co/templates/preview/mixkit-simple-opener-transition-755.zip"

  # Página completa: https://mixkit.co/free-final-cut-pro-templates/transitions/

OPÇÃO C — Instalar direto após download:
1. Clica duas vezes no .zip → descompacta
2. Clica duas vezes no .fcptemplate → FCP instala automaticamente
3. Reinicia o FCP se necessário

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 5: INSTALAR TEMPLATES RYAN NANGLE (.zip → pasta .localized)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Vai a https://www.finalcutplugs.com/ e escolhe o pack
2. No checkout Sellfy, introduz o teu email
3. Recebes o link de download por email
4. Descompacta o .zip
5. Copia a pasta .localized para:
   ~/Movies/Motion Templates.localized/Transitions.localized/

No Terminal:
  cp -r ~/Downloads/"Free Shake Transition.localized" \
    ~/Movies/"Motion Templates.localized"/"Transitions.localized"/

6. Reinicia o Final Cut Pro
7. Vai a: Efeitos → Transições → procura pelo nome do pack

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 6: INSTALAR BRETFX (.dmg)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Vai a https://www.bretfx.com/product/power-tools/
2. Completa o checkout (email necessário)
3. Clica duas vezes no .dmg para montar
4. Dentro do volume montado, abre o instalador .pkg
5. Segue as instruções do instalador
6. Ejecta o volume após instalação
7. Reinicia o Final Cut Pro

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 7: INSTALAR FXFACTORY PLUGINS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Descarrega e instala a app FxFactory de: https://fxfactory.com/download/
2. Abre FxFactory e cria uma conta gratuita (email necessário)
3. Procura o plugin gratuito dentro da app (ex: "Andy's Swish Transitions")
4. Clica em "Get" / "Install"
5. FxFactory gere a instalação automaticamente
6. Os plugins ficam disponíveis no FCP sem configuração adicional

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 8: USAR CINEPACKS (.mov overlays)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Os ficheiros CinePacks são vídeos .mov, não plugins nativos. Usam-se assim:

1. Vai a https://cinepacks.store/collections/free-packs/transitions
2. Escolhe um pack, introduz email no checkout
3. Descompacta o .zip recebido
4. Importa os .mov para o teu projeto FCP
5. Arrasta o clip .mov para a timeline, ACIMA do teu vídeo
6. No inspector, muda o "Blend Mode" para:
   - "Screen" → para efeitos sobre fundo preto (maioria dos packs)
   - "Add" → para efeitos luminosos (flares, glows)
   - "Multiply" → para efeitos sobre fundo branco (papel, etc.)
7. O efeito mistura-se com o teu vídeo

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 9: INSTALAR MOTIONVFX (via mExtension)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cria conta gratuita em: https://www.motionvfx.com
2. Descarrega mExtension: https://www.motionvfx.com/mextension
3. Instala mExtension (é um plugin para o FCP)
4. Abre o Final Cut Pro → verás o browser mExtension no painel
5. Navega até "Free Elements Collection"
6. Clica nos itens para instalar diretamente no FCP

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 10: VERIFICAR INSTALAÇÃO NO FINAL CUT PRO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

No Final Cut Pro:
1. Abre o browser de efeitos (tecla Command+5)
2. Clica em "Transições" no topo
3. Os packs instalados aparecem como categorias na coluna esquerda
4. Para usar: arrasta a transição para o ponto de corte entre dois clips

Se uma transição não aparecer após instalação manual:
- Verifica se a copiaste para a pasta correta
- Reinicia o Final Cut Pro (Command+Q e reabre)
- Verifica compatibilidade: Menu → Final Cut Pro → Sobre (ver versão)

PARTE 11: COMPATIBILIDADE E ALERTAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VERSÕES FCP requeridas por pack:
  - FCP 10.2.x → packs antigos (Ryan Nangle clássicos, 2015-2016)
  - FCP 10.4.x → packs modernos (2018-2022) — maioria dos packs
  - FCP 10.6.x → packs recentes (2023+) — Ryan Nangle AI Pack, Flash, etc.

Para ver a tua versão:
  Final Cut Pro → Sobre o Final Cut Pro (no menu superior)

APPLE SILICON (M1/M2/M3/M4):
  - BretFX: nativo Apple Silicon
  - MotionVFX 10.4.8+: nativo Apple Silicon
  - Packs antigos (10.2.x): podem exigir Rosetta 2

NUNCA instales plugins de fontes não verificadas.
Todos os links neste documento são de criadores reconhecidos e legítimos.
